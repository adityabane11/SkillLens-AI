SKILLLENS AI — VERCEL DEPLOYMENT (FIXED)

IMPORTANT: Deploy the CONTENTS of this folder from the project root. The root must contain app.py, requirements.txt, vercel.json, templates/, models/, data/, and public/.

1. Extract this ZIP.
2. Upload/push all files and folders inside the extracted folder to the GitHub repository connected to Vercel. Do not upload the ZIP itself.
3. In Vercel > Project > Settings > Build and Deployment, set Root Directory to the folder containing app.py (usually ./ or leave blank). Do not set an Output Directory.
4. Commit and push the updated files, or redeploy the latest commit in Vercel.
5. Open the new Production deployment's main URL.

This package removes the old catch-all rewrite to /api/index and uses Vercel's Flask detection from root-level app.py. The vercel.json function includeFiles setting explicitly includes templates, model, data, and static files so Flask can find index.html at runtime. CSS and JavaScript are also copied to public/static for Vercel static serving.

If it still shows Not Found: open the deployment in Vercel, go to Logs/Runtime Logs, and share the exact error or the deployment URL. Do not share secret environment variables.
